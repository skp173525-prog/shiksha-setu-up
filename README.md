# Shiksha Setu UP - Free Education for Poor Children

Free Education Platform for poor children of UP - Built for My Bharat Hackathon

## Problem Statement
Many poor children in Uttar Pradesh do not have access to free and quality education due to financial constraints and lack of resources.

## Solution
Shiksha Setu is a free learning platform that provides video lectures, notes, and quizzes for students from Class 1 to 12.

## Tech Stack
- Frontend: Flutter
- Backend: Firebase (Authentication, Firestore Database)
- Video Integration: YouTube API

## Architecture
App (Flutter) -> Firebase Backend -> YouTube API -> Student

## Features
- Free video classes for Class 1-12
- Offline notes access
- Practice quizzes
- Progress tracking for students
- Low-data mode for rural areas

## Sample Data
Test data for 100 students is configured in Firebase for prototype testing.

## Future Scope
- Add more regional languages (Hindi, Bhojpuri)
- Doubt-solving with teachers
- Scholarship information
